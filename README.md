# ForteBank Datathon

Совместный проект локального анализа видео кассового обслуживания.

Компоненты разрабатываются раздельно: локальное восприятие видео, проверка правил и оценка качества, backend, frontend. Интерфейсы между ними фиксируются в документации соответствующих модулей. Готовность отдельного модуля не означает готовность всего сервиса.

Видео, кадры, тестовые данные, API-ключи и веса моделей не размещаются в Git. Для локальных данных используйте игнорируемую директорию `local_data/`.

После предварительной загрузки весов обработка должна выполняться внутри сервиса без обращения к внешним AI API. Видео, кадры и их описания не передаются облачным AI-сервисам.
