# Детектор предметов кассы (RF-DETR)

Зачем: по матрице 42 роликов (схема «таймлайн + чек-лист») 11 из 14 проверок не сработали ни разу, и все
упираются в предметы, которые Qwen не видит на целом кадре: деньги, документ, сейф открыт/закрыт, дверь,
экран ноутбука, счётчик купюр, мешок. Классы и связь с проверками — `classes.py`.

Конвейер — три шага, всё локально, видео и кадры никуда не уходят:

| Шаг | Скрипт | Что делает | Где |
|---|---|---|---|
| 1 | `make_frames.py` | кадры из роликов (редко по всему ролику, часто около нарушения), группы и ракурсы | любая машина, ~30 с на 42 ролика |
| 2 | `autolabel.py` | черновые рамки через Qwen3-VL (llama-server), второй проход по увеличенным вырезкам | машина с llama-server, ~7 с/кадр |
| — | глазами | просмотр `overlays/`, правка ошибок | человек |
| 3 | `train.py` | деление по группам/ракурсам, обучение RF-DETR | RTX 4060, Qwen выгружен |

## Команды (Windows, PowerShell, из `vision/tools/detector`)

```powershell
# окружение: vision + обучение RF-DETR (torch с CUDA ставится отдельно, по инструкции pytorch.org)
pip install -e ..\..[detector] "rfdetr[train]==1.11.2"
$env:PYTHONPATH = "..\..\src"

# 1. кадры: VIDEOS — папка с 42 .mov из официального датасета, team_labels.csv — разметка команды
python make_frames.py --videos C:\data\open\videos --labels C:\data\team_labels.csv --out C:\det\frames

# 2. черновая разметка через уже запущенный llama-server (ключ — из файла, не аргументом)
python autolabel.py --frames C:\det\frames --out C:\det\labels --url http://127.0.0.1:8080 --key-file C:\path\.vlm_key

# 3. сначала посмотреть деление, потом учить (llama-server остановить: 8 ГБ на двоих не хватит)
python train.py --frames C:\det\frames --coco C:\det\labels\autolabel.coco.json --out C:\det\run1 --dry-run
python train.py --frames C:\det\frames --coco C:\det\labels\autolabel.coco.json --out C:\det\run1 --epochs 40
```

## Что важно знать

- **Деление честное.** Группа = ролик + его чистый близнец + побайтные дубли (Х-4 = Х-47, Х-5 = Х-48),
  целиком в одной части. Test — целый ракурс (по умолчанию «кассир спиной к камере»: Х-1…Х-5, Х-48 и
  близнец Х-17), модель его не видит — это репетиция «финальное видео с другого угла».
  Ракурсы находятся сами по похожести кадров (на открытом наборе 12 постановок камеры).
- **Авторазметка — черновик.** Крупное (сейф, счётчик, ноутбук, дверь) Qwen находит верно; мелочь и
  состояния ошибается: экран с рабочим столом подписывала «заблокирован». Перед обучением просмотреть
  `overlays/`, ошибки удалить в COCO (CVAT / Label Studio локально).
- **Ключ в замке сейфа (Х-22) — 3–5 пикселей** на кадре 464×848. Ни VLM, ни детектор его не возьмут; это
  ограничение записать в README сдачи, а не обещать.
- `autolabel.py` кеширует ответы в `labels/raw/`: обрыв не страшен, повторный запуск продолжит.
