# Проверка backend — 17 октября 2026

Локальная среда: Windows, Python 3.12, FFmpeg/ffprobe 9.0.2, зависимости из `requirements.lock`. Проверка выполнена на CPU; настоящая ML-модель отсутствует.

## Что выполнено

Полный локальный набор: **34 теста**. Проверка согласованности установленных Python-зависимостей: `pip check` без ошибок.

- Автоматические тесты API: авторизация жюри, отдельные публичные UI-маршруты, сохранение до ответа, лимит очереди, лимит потокового тела без Content-Length, медленная загрузка, истечение срока, запрет development-конфигурации в production.
- SQLite/worker: атомарное получение задания, защита от старой попытки, блокировка второго worker, авария процесса, восстановление после принудительного завершения, зависание модели, срок с учётом очереди, проверка срока после ожидания блокировки SQLite.
- Результаты: оба verdict на синтетических адаптерах, несколько событий, настоящие JPEG из синтетического исходника, повреждённый MOV, незавершённый анализ и отсутствие ML.
- VideoIO: VFR, ненулевой start_time, соответствие цвета кадра его PTS, поворот на 90°, неполный файл, запрет плейлиста под расширением MOV, синтетическое длинное видео.
- Пять одновременных HTTP-загрузок через тестовый ASGI-клиент и настоящий процесс worker: 1,67–2,47 секунды от начала загрузки до результата, включая очередь. Файлы синтетические, по одной секунде, анализатор тестовый. Это **не измерение скорости ML**.
- Настоящий HTTP-сервер на `127.0.0.1:8000`: проверены ключ, загрузка, polling и корректный `failed` при development-адаптере. `/health/ready` возвращает 503 без настоящей модели.
- Самый длинный ролик датасета проверен только локальным декодером: 142,533 секунды, 4273 кадра, 464×848. Полное чтение PTS и проверка декодирования заняли 10,393 секунды. Содержимое видео и кадры не передавались внешним AI-сервисам.
